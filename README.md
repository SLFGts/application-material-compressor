# 轻材料 · 网申材料压缩

在线使用：https://slfgts.github.io/application-material-compressor/

支持 PDF、PNG、JPG、JPEG 混合添加和四种格式输出。文件读取、转换、拼接、压缩及打包均在浏览器本地完成，不上传材料，无需登录或 API Key。

## 使用流程

1. 添加一份或多份文件，按文件、图片或 PDF 页面勾选，用箭头调整顺序。
2. 选择 PDF、PNG、JPG 或 JPEG。JPG 与 JPEG 使用相同的编码，下载扩展名不同。
3. 拖动大小滑块，或输入 KB 数值。范围为 50KB 到 10MB，默认 200KB，可一键恢复。1KB 按 1,000 字节计。
4. 合并模式：图片输出为一张纵向长图；PDF 输出为一个多页文件，每个所选项占一页。分别导出模式下，每个所选项独立输出。
5. 生成后预览、检查大小并下载。多张/多份结果支持 ZIP 打包。PDF 预览支持翻页及原尺寸查看。

大小是上限而非目标值。合并模式限制整个文件；分别导出模式限制每个文件；ZIP 大小不受此上限限制。结果显示生成时使用的上限，修改选择、顺序、格式或大小后需重新生成。

## PDF 输出说明

PDF 页面采用 JPEG 图片嵌入，每个所选项对应一页，保持页面比例、按所选顺序排列。原 PDF 的可选择文字、表单、签名、超链接等交互内容不会保留。PDF 文件保存后再次检查最终字节数，包含文档结构开销；无法满足时提示提高上限或减少内容。

## 本地运行

```bash
python3 -m http.server 8765
```

打开 http://localhost:8765 。需通过 HTTP(S) 访问，以便加载 PDF 工作线程。

## 部署

GitHub Pages 从 main 分支根目录发布，`.nojekyll` 禁用 Jekyll 处理。更新分支中的网页文件后会自动发布。所有资源均采用相对路径。

## 项目结构

- `index.html`、`style.css`：页面、大小滑块、响应式样式。
- `app.js`：文件读取、选择、排序、预览和下载。
- `compress.js`：图片压缩及可调字节上限。
- `pdf-export.js`：图片化 PDF 生成、最终大小检查。
- `vendor/`：PDF.js 3.11.174（Apache-2.0）、JSZip 3.10.1（MIT）、pdf-lib 1.17.1（MIT），含许可证。

## 限制

单份输入最大 50MiB，加密 PDF 需先解除密码。上限越低、材料越多，清晰度可能越差，请放大检查后提交。超长图片工作画布最多约 1200 万像素、最长约 16000 像素。材料和结果仅保存在当前页面内存中，刷新后清空，不跨设备同步。
