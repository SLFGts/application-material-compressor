# 轻材料 · 网申材料压缩

在线使用：https://slfgts.github.io/application-material-compressor/

支持 PDF、PNG、JPG、JPEG 混合添加和四种格式输出。文件读取、转换、拼接、压缩及打包均在浏览器本地完成，不上传材料，无需登录或 API Key。

## 界面

简洁文档工作台：桌面左侧添加、选择和编辑材料，右侧设置格式、输出方式和大小；手机按任务顺序排列。添加后上传区收起，为页面预览留出空间。修改材料或设置后，旧结果会提示重新生成。整理、导出、下载三个区域使用统一的面板、标题和间距。象牙白面板配奶油色背景，格式说明折叠显示，减少重复文案；预览和 PDF 编辑器沿用同一配色。

## 使用流程

1. 添加一份或多份文件，按文件、图片或 PDF 页面勾选，用箭头调整顺序。
2. PDF 每页可点击“裁剪 / 贴图”：拖动框选或输入百分比裁剪；添加多张 PNG/JPG/JPEG，拖动定位、等比例缩放，支持透明 PNG。可将裁剪同步到同一 PDF 全部页面；贴图按页独立保存。取消会丢弃本次草稿，可恢复整页或重置本页编辑。
3. 选择 PDF、PNG、JPG 或 JPEG。JPG 与 JPEG 使用相同的编码，下载扩展名不同。
4. 拖动大小滑块，或输入 KB 数值。范围为 50KB 到 10MB，默认 200KB，可一键恢复。1KB 按 1,000 字节计。
5. 合并模式：图片输出为一张纵向长图；PDF 输出为一个多页文件，每个所选项占一页。分别导出模式下，每个所选项独立输出。
6. 生成后预览、检查大小并下载。多张/多份结果支持 ZIP 打包。PDF 预览支持翻页及原尺寸查看。

大小是上限而非目标值。合并模式限制整个文件；分别导出模式限制每个文件；ZIP 大小不受此上限限制。结果显示生成时使用的上限，编辑页面或修改选择、顺序、格式、大小后需重新生成。

## PDF 输出说明

优先复制原 PDF 页面并应用裁剪、贴图，大小允许时保留原文字。若完整文件超过所选上限，或原页面无法复制，则将页面转为图片后压缩生成 PDF；结果标记“保留原页面”或“图片化压缩”。图片化时文字不可选择。表单、签名、超链接等交互内容不保证保留，请下载后核对。

裁剪修改页面可见区域，不等于安全删除或脱敏；原 PDF 中被裁去的内容可能仍在输出文件内。贴图坐标随原页面显示方向计算，支持旋转页及已有裁剪区域。所有编辑同时应用到 PDF、PNG、JPG、JPEG 输出。原文件不会被覆盖。

每个所选项对应一页，保持裁剪后的页面比例、按所选顺序排列。保存后检查最终字节数，包含 PDF 文档结构开销；无法满足时提示提高上限或减少内容。

## 本地运行

```bash
python3 -m http.server 8765
```

打开 http://localhost:8765 。需通过 HTTP(S) 访问，以便加载 PDF 工作线程。

## 部署

GitHub Pages 从 main 分支根目录发布，`.nojekyll` 禁用 Jekyll 处理。更新分支中的网页文件后会自动发布。所有资源均采用相对路径。

## 项目结构

- `index.html`、`style.css`：工作台布局、统一样式、大小滑块和响应式样式。
- `PRODUCT.md`、`DESIGN.md`：产品约束与最终设计规范。
- `app.js`：文件读取、选择、排序、预览和下载。
- `compress.js`：图片压缩及可调字节上限。
- `page-edit.js`：逐页裁剪、贴图编辑及坐标转换。
- `pdf-export.js`：原页面 PDF 编辑、图片化压缩回退、最终大小检查。
- `vendor/`：PDF.js 3.11.174（Apache-2.0）、JSZip 3.10.1（MIT）、pdf-lib 1.17.1（MIT），含许可证。

## 限制

单份输入最大 50MiB，加密 PDF 需先解除密码。上限越低、材料越多，清晰度可能越差，请放大检查后提交。超长图片工作画布最多约 1200 万像素、最长约 16000 像素。材料和结果仅保存在当前页面内存中，刷新后清空，不跨设备同步。
